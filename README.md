# How to read a frame and hear what belongs in it

A guide to AI-assisted sound design, written at three depths so you can pick the
one that fits you today and change it whenever you like.

**Read it: https://markoboskoauroville.github.io/SOUND_DESIGN_GUIDE/**

| | For | Covers |
|---|---|---|
| **The Runner** | new to all of this | what sound design is, why blank paper means silence, the four layers |
| **The Assistant** | you will run the tool | commands, the four sound worlds, reading a brief, what will bite you |
| **Supervising Editor** | you will change the tool | why this is not a video-to-audio model, test discipline, what is unproven |

## The idea in one line

A general vision model trained on photographs, shown a pencil drawing of a
runner on blank paper, returns a stadium. There is no stadium. The whole system
exists to stop that from happening: the film's rules are stated to the model
before it is allowed to look, and what comes back is a *brief* for a human to
argue with, never audio and never a decision.
